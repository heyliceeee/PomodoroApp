# Pomodoro App

Uma aplicação Pomodoro desenvolvida com interface gráfica, pensada para melhorar o foco, a produtividade e a gestão equilibrada do tempo. O sistema alterna automaticamente entre períodos de trabalho, pausas curtas e pausas longas, seguindo a lógica tradicional da técnica Pomodoro.

## 🎯 Objetivo

Ajudar a manter ciclos de concentração profunda, intercalados com momentos de descanso, promovendo um ritmo de trabalho sustentável e eficiente.

## ⏱️ Funcionamento

A aplicação gere automaticamente três tipos de sessões:

- **Work** — período de foco contínuo  
- **Short Break** — pausa breve para recuperar energia  
- **Long Break** — descanso prolongado após vários ciclos concluídos  

Cada sessão é apresentada com um temporizador visual e um título correspondente.

## 🧩 Ciclos e Progresso

O progresso é acompanhado através de marcas visuais que representam sessões de trabalho concluídas. Após cada ciclo, o estado atual é atualizado de forma automática, garantindo uma experiência fluida e intuitiva.

## 🎨 Interface

A interface utiliza cores suaves, ícones intuitivos e elementos visuais simples, garantindo uma experiência agradável e fácil de interpretar.  
Inclui:

- **Botão Start** para iniciar o ciclo  
- **Botão Reset** para reiniciar o temporizador  
- Indicadores de sessão e progresso  
- Temporizador central com destaque visual  

## 🍅 Ideal para

- Estudantes  
- Profissionais que trabalham por blocos de foco  
- Pessoas que procuram melhorar a gestão do tempo  
- Quem pretende manter uma rotina equilibrada entre produtividade e descanso  

## 📌 Nota

Os tempos utilizados podem ser ajustados para demonstrações rápidas ou para sessões reais de produtividade, mantendo sempre o comportamento automático entre ciclos.
